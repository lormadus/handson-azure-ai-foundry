
## Azure AI Foundry 에서 Project 만들기 ##

1. Azure AI Foundry 사이트의 우측 상단의 'Create Project'를 클릭합니다.

![image](https://github.com/user-attachments/assets/68ebae1b-e5c5-46bd-86c7-e90a6f93013a)

2. Proejct 이름을 확인하고 하단 'Create' 버튼을 클릭합니다.

![image](https://github.com/user-attachments/assets/248b30fa-0aa9-4355-8be9-a104768d842c)

3. Project 생성하기를 클릭하면 AI Hub 및 스토리지와 다른 리소들이 자동을 생성됩니다.

![image](https://github.com/user-attachments/assets/0ffc3bce-4a4a-49ab-96d3-3c723803c1f2)

4. 팝업 설명을 'Close'버튼을 눌러 종료하면 AI Foundry 프로젝트를 사용할 준비가 마무리 됩니다.

![image](https://github.com/user-attachments/assets/fd3152be-ee79-4943-95cc-d23e6f2bc66c)
